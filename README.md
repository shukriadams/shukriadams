I'm a devops programmer and system architect. I've programmed since the 90's in various fields, the last ten
years as an architect in mixed tech/creative settings like media and game development. My work is often writing custom servers, applications, tools and workflows for other developers to use. I open source a lot of that here. 

## Noteworthy projects 

- [Porter](https://github.com/shukriadams/porter) : I like code reuse very much, I've written several my own NPM modules, and I like the NPM workflow so much that I wrote an NPM-style package manager for C#. Packages are source,
stored in git and can contain non-colliding nested dependencies of their own.

- [Tetrifact](https://github.com/shukriadams/tetrifact) : A build storage server tuned for game studios. It can store
thousands of Unreal-sized builds, and scales up to millions of files.

- [Restartinator](https://github.com/shukriadams/restarternator) : A dashboard to remote control and monitor large
fleets of PCs using airgapped smart plugs.
